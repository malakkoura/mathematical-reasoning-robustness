# Data And Licensing

Raw benchmark records are not included. Obtain GSM8K and CogMath from their original sources and follow their licences/access terms. The Qwen/Qwen3-4B-Base model must be used under its model-card licence.

This release includes code, configuration files, and lightweight aggregate summaries. Validation prediction JSONL files are omitted because they contain benchmark questions. Model weights, adapter checkpoints, tokenizers, caches, and held-out test records are also omitted.
